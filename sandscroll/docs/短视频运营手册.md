# 「一沙一世界」数字沙画短视频 · 运营手册

> 适用平台：TikTok（海外）与小红书（国内）。同一批视频也可用于抖音、视频号、YouTube Shorts。
> YouTube 直播权限开通后，可随时启用《运营手册》中的 24 小时直播方案，与短视频互相导流。

---

## 1. 定位

| 项目 | 内容 |
|---|---|
| 系列名 | **一沙一世界 · A World in a Grain of Sand**。出自英国诗人布莱克的名句 “To see a World in a Grain of Sand”，中文译作「一沙一世界」，本身就是东西方的一次相遇 |
| 形式 | 竖屏 9:16，每条约 45 秒：1 秒抛出钩子 → 沙画快速成形 → 题诗 → 钤印 → 诗句与互动提问 |
| 内容主线 | 正能量 × 国风 × 解压：每一集用一句古诗讲一个积极的主题（团圆、坚持、奋斗、松弛、坚韧、友谊、包容） |
| 差异化 | ① 竖屏即立轴，天然适合中国画构图；② 音乐原创、实时生成，没有版权风险；③ **代码生成、没有一粒真沙**，这既是需要主动说明的事实，也是吸引人的反差看点 |

## 3. 生成视频

```bash
cd sandscroll
npm install && npm run setup
node tools/make-shorts.mjs --out shorts            # 生成全部 8 集（约 1 分钟/集）
node tools/make-shorts.mjs --only moon,panda       # 只生成某几集
node tools/make-shorts.mjs --preview --snap 4      # 低清快速预览 + 每 4 秒一张截图
```

每集输出 4 个文件：

| 文件 | 用途 |
|---|---|
| `EPxx-名称.mp4` | 1080×1920、30fps、H.264 + AAC，约 45 秒、20–30 MB |
| `EPxx-名称-cover-9x16.jpg` | TikTok / 抖音封面 |
| `EPxx-名称-cover-3x4.jpg` | 小红书封面（3:4，标题在下方，不遮挡画面主体） |
| `EPxx-名称.txt` | 两个平台的文案 |

- 换一个 `--seed` 就会得到同一主题的另一幅画（细节不同），适合二次发布或做 A/B 测试。
- 新增一集：在 `src/shorts/scenes/` 写一个竖屏场景，在 `src/shorts/index.js` 登记，在 `src/shorts/copy.js` 写好文案。

## 4. 发布规范

### 小红书

- **格式**：竖屏视频直接上传；封面在「编辑封面」中选择「上传封面」，用 `cover-3x4.jpg`。
- **标题**：20 字以内，以情绪或利益点开头（已按此写好），带 1 个 emoji。
- **正文**：诗句加出处 → 一句共鸣 → 一个互动问题 → 生成方式说明。
- **话题**：5–8 个，泛话题（#国风 #治愈系 #解压视频）搭配精准话题（#中秋节 #大熊猫）。
- **时间**：午间 12:00–13:00，晚间 19:00–22:00。
- **AI 标识**：发布页勾选「内容由 AI 生成」或添加相应声明。按《人工智能生成合成内容标识办法》（2025 年 9 月 1 日起施行），AI 生成的合成内容须显著标识；正文最后一行也已写明。

### TikTok

- **格式**：1080×1920 竖屏；可在 TikTok 内选用 `cover-9x16.jpg` 对应的画面作封面，并加上标题文字。
- **AI 标识**：发布前在「更多选项」里打开 **AI-generated content** 标识。
- **文案**：英文，开头一句是情绪钩子，中间一句诗的英文译文，结尾说明 “Digital sand art, made with code.”
- **话题**：3–6 个（#sandart #satisfying #chineseart 加上题材话题）。
- **时间**：面向北美观众时，当地晚上 7–10 点，约为北京时间次日早上 7–10 点。
- **声音**：保留原声（原创古筝音乐）。若原声被他人复用，会形成你自己的 “original sound” 入口。

### 两个平台通用

- 前 1 秒决定划走率：钩子已经放在第 1 帧，不要在视频前面再加片头。
- 结尾有「下一幅画什么？评论区告诉我」：把评论区的点子排进下一批内容，并回复「安排！」，这会显著提升互动。
- 同一集不要同时带两个平台的水印互传，请分别上传原始 MP4。

## 5. 内容边界（正能量、少风险）

| 做 | 不做 |
|---|---|
| 以古诗、节日、自然、友谊、努力等普世主题表达正能量 | 不使用领导人姓名、肖像做标题、封面或话题（小红书等平台对个人账号发布时政内容限制严格） |
| 以文化意象呈现中美民间友好（熊猫、长城与金门大桥、牡丹与玫瑰） | 不做政治评论，不参与争论；评论区出现争执时只回应作品本身 |
| 主动说明「代码生成、没有一粒真沙」 | 不把数字沙画说成真人手工沙画，不冒充手艺人 |
| 时效信息先核实再写（如大熊猫抵达亚特兰大的时间） | 不编造数据或新闻 |

## 6. 数据复盘（每周一次）

| 指标 | 看什么 | 行动 |
|---|---|---|
| 完播率 / 平均观看时长 | 45 秒里观众在哪里流失 | 流失集中在前 5 秒：换钩子；集中在中段：把 `--draw` 调短（例如 24 秒） |
| 互动率（赞、藏、评） | 哪个主题最能引发共鸣 | 同主题做「续集」，例如坚持系列、友谊系列 |
| 收藏率（小红书） | 诗句与配文是否值得收藏 | 高收藏的内容可做合集或整理成笔记 |
| 涨粉转化 | 哪集带来关注 | 置顶该集，并在主页简介中呼应系列名 |
| 评论区点子 | 观众想看什么 | 排进下一批（新增场景很快，见第 3 节） |

**30 天初始目标（用于校准）**：发布 20–30 条；小红书单条平均 500+ 播放，至少 1 条过万；TikTok 至少 1 条进入 5,000+ 播放；平均完播率 ≥ 30%。

## 7. 后续选题池

- **二十四节气**：每个节气一幅，长期、固定的更新节奏。
- **诗人系列**：李白、杜甫、苏轼各出一集，配上一句正能量名句。
- **观众点单**：把评论区点名最多的画面做出来，标题写「应评论区要求」。
- **幕后揭秘**：「这幅沙画没有一粒真沙」，展示代码怎样一笔一笔「画」出来，适合吸引科技向用户。
- **双语朗读**：在同一条视频上叠加诗句的中英朗读（需另行录音）。
